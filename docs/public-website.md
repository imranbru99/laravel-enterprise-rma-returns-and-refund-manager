# Public Website, Demo Sandbox & Customer Portal

## 1. Enterprise Marketing Website
The application includes a complete, mobile-responsive enterprise public website built with Tailwind CSS:
- `/` — Master Landing Page with value proposition, metrics, testimonials, and feature highlights.
- `/features` — In-depth breakdown of the 8 module categories and 90 capabilities.
- `/workflow` — Visual interactive explanation of the 6-stage reverse logistics lifecycle.
- `/industries` — Specific use cases for Electronics, Fashion, 3PL, and Retail Chains.
- `/pricing` — SaaS subscription plans (Starter, Growth, Enterprise) with monthly/annual billing toggles.
- `/docs` — Developer documentation, architecture overviews, and API references.
- `/contact` — Enterprise inquiry and sales demo booking form.
- `/register` — 1-minute tenant registration with automated onboarding wizard.

## 2. Interactive Sandbox Showcase (`/demo`)
Features:
- **1-Click Quick Login**: Instant switch between 8 pre-seeded demo user accounts without typing passwords.
- **Interactive RMA Step Progression**: Live state machine runner advancing an RMA through Request -> Approval -> Receiving -> Inspection -> Refund, with real-time UI logs and financial balances.

## 3. Customer Self-Service Portal (`/portal`)
- View past orders and current return statuses.
- Multi-step return request wizard with photo upload and reason selection.
- Download prepaid PDF return labels and drop-off vouchers.
- File dispute appeals for rejected RMAs.
- Guest Order Lookup (`/portal/guest-lookup`) using Order Number and Email.
